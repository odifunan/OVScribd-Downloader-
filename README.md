# Scribd → Excel V2

Web app untuk memeriksa URL Scribd dan mengonversi file yang Anda unduh secara resmi (PDF/DOCX/TXT/CSV/XLS/XLSX) menjadi Excel dengan preview.

## Jalankan lokal
1. Install Node.js 20+.
2. `npm install`
3. `npm start`
4. Buka `http://localhost:3000`

## Railway
Deploy folder ini sebagai Node.js app. Start command: `npm start`.

Catatan: aplikasi tidak membypass login, subscription, CAPTCHA, DRM, paywall, atau proteksi Scribd. Jika dokumen tidak punya tombol Unduh, gunakan alur resmi Scribd atau unggah file yang memang Anda berhak mengolah.
